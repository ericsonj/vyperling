# Migrating from Ceedling to vyperling

No Ruby. No Gemfile. Drop-in replacement for most Ceedling projects.

## Quick start

```bash
pip install vyperling   # or: pipx install vyperling
vpl test                # equivalent to: ceedling test:all
```

## project.yml → forge.yml

| Ceedling `project.yml` | `forge.yml` equivalent | Notes |
|------------------------|------------------------|-------|
| `:project: :build_root: build` | `project.build_dir: build` | |
| `:project: :test_file_prefix: Test` | `conventions.test_prefix: "Test"` | default is `test_` |
| `:source_root: ['src/**']` | `project.src_dirs: [src]` | rglob covers subdirs |
| `:test_root: ['test/**']` | `project.test_dir: test` | rglob covers subdirs |
| `:include_root: ['src/**']` | `project.include_dirs: [src]` | |
| `:support_root: test/support` | `project.support_srcs: [test/support/*.c]` | glob supported |
| `:defines: :test: ['*': [TEST]]` | `compiler.defines: [TEST]` | global only (no per-file) |
| `:flags: :test: :compile: :Foo: [-DVAL=1]` | `compiler.defines: [VAL=1]` | global; per-unit not yet supported |
| `:libraries: :test: [m]` | `compiler.extra_ldflags: [-lm]` | ldflags go AFTER objects |
| `:cmock: :mock_prefix: Mock` | `conventions.mock_prefix: "Mock"` | default is `mock_` |

### Minimal forge.yml for a Ceedling project

```yaml
project:
  name: my_project
  src_dirs: [src]
  include_dirs: [src]
  test_dir: test

conventions:
  test_prefix: "Test"
  mock_prefix: "Mock"
  test_naming: "camelCase"

compiler:
  defines: [TEST]
  extra_ldflags: [-lm]   # if your project uses math.h
```

## Naming conventions

Ceedling uses `Test` for files and `test` for functions:

```c
// File: TestFoo.c
void testFooDoesBar(void) { ... }   // lowercase test + camelCase
```

vyperling defaults to `test_` prefix and snake_case:

```c
// File: test_foo.c
void test_foo_does_bar(void) { ... }
```

Set `conventions` in `forge.yml` to use Ceedling files verbatim:

```yaml
conventions:
  test_prefix: "Test"      # discover Test*.c files
  mock_prefix: "Mock"      # generate Mock*.h/c files
  test_naming: "camelCase" # extract testFooBar() and TestFooBar() functions
```

With these settings, **no file renames needed**.

## Mock API — identical to CMock

The mock API generated by vyperling is identical to CMock. No changes to test bodies:

```c
// Works in both Ceedling and vyperling:
Uart_Send_ExpectAndReturn(0x41, 1);
Uart_Flush_Expect();
Uart_Read_IgnoreAndReturn(0);
Uart_Read_IgnoreArg_buf();
```

The only difference is the generated header filename:
- Ceedling: `MockUart.h` (with `Mock` prefix)
- vyperling default: `mock_uart.h` (with `mock_` prefix)
- vyperling + `mock_prefix: "Mock"`: `MockUart.h` ✓

## Integration tests (no source match)

Tests that cover multiple modules (no single SUT file) need `extra_srcs`:

```yaml
project:
  extra_srcs:
    TimerIntegrated:
      - src/TimerConductor.c
      - src/TimerHardware.c
      - src/TimerModel.c
```

Equivalent to Ceedling's ability to link multiple sources per test.

## Mock includes with path prefix

Ceedling supports `#include "calculators/MockFoo.h"` when a mock lives in a subdirectory. vyperling generates all mocks flat in `mock_dir`. To support path-prefixed includes, create a symlink:

```bash
ln -sf . mocks/calculators
```

Then `#include "calculators/MockFoo.h"` resolves to `mocks/MockFoo.h` ✓.

## Comparison script

After running both tools, compare results:

```bash
# Run Ceedling
ceedling test:all utils:junit_tests_report  # or your JUnit plugin

# Run vyperling
vpl test --output junit

# Compare
python scripts/compare_results.py \
  --ceedling ceedling_results.xml \
  --vpl build/native/results.xml
```

## Unsupported Ceedling features

| Feature | Ceedling | vyperling | Notes |
|---------|----------|-----------|-------|
| Partials | ✓ | ✗ | Tests static/inline functions via source injection |
| CException | ✓ | ✗ | Exception handling for C |
| Strict ordering | ✓ | ✗ | CMock `strict_ordering: true` |
| Per-file defines | ✓ | ✗ | `flags: test: compile: :File: [-DVAL]` |
| gcov plugin | ✓ | `vpl test --coverage` | Different invocation, same gcovr output |
| `ceedling module:create` | ✓ | `vpl new` | Scaffold only, not module generator |
| Release build | ✓ | ✗ | vyperling is test-only |
| Test preprocessor | ✓ | ✗ | pycparser handles most cases |
